# outlook-releases

Public release build pipeline and prebuilt binary distribution repository for **Microsoft Outlook Terminal Client & AI Agent Toolkit (`outlook` / `@shinick/outlook`)**.

> Source code lives in the private repository `shinick-dev/outlook`.

## Quick Install

```bash
npm install -g @shinick/outlook
outlook --version
outlook login
outlook
```

## Supported Platforms

- `outlook-win32-x64` (`x86_64-pc-windows-msvc`)
- `outlook-win32-arm64` (`aarch64-pc-windows-msvc`)
- `outlook-darwin-arm64` (`aarch64-apple-darwin`)
- `outlook-darwin-x64` (`x86_64-apple-darwin`)
- `outlook-linux-x64` (`x86_64-unknown-linux-gnu`, `GLIBC 2.28` / AlmaLinux 8+)
- `outlook-linux-arm64` (`aarch64-unknown-linux-gnu`, `GLIBC 2.28` / AlmaLinux 8+)
